# Падающий продакшен

В 03:17 продакшен издал протяжный stack trace и начал падать прямо на глазах у команды. Дежурный Вася — самоучка на Rust: на кружок он не ходил, потому что был уверен, что «компилятор и так всё объяснит». Компилятор объяснил. Подробно. Вася заплакал, сервер упал ещё раз.

Вася хотел взять первое слово из сообщения сервиса, дописать к сообщению ` rust`, передать строку дальше и посмотреть на неё сначала через изменяемую, а потом через обычную ссылку. Но в коде строка одновременно оказалась заимствована и изменена, использована после перемещения, а `&mut` попытался подружиться с `&` в одно и то же время.

## Задача

Помогите Васе починить программу, не меняя её задуманный результат. Реализуйте функцию `process(text: String) -> String`:

1. Найдите первое слово исходной строки. Слова разделяются пробельными символами; если слов нет, первая строка результата должна быть пустой.
2. Передайте владение строкой переменной и допишите к ней ` rust`.
3. Верните три строки с завершающим `\n`: первое слово исходного сообщения, изменённое сообщение (показанное через `&mut`), затем то же сообщение (прочитанное через `&`).

Нужно сохранить порядок действий и добиться успешной компиляции. Клонировать всю строку три раза — план, который Вася предложил в 03:18, — не требуется.

## Пример

Для входной строки `hello MATMEX` результат `process` должен быть:

```text
hello
hello MATMEX rust
hello MATMEX rust
```

Для строки `Rust это отец` результат:

```text
Rust
Rust это отец rust
Rust это отец rust
```
